# ChannelScope: where it stands

**Version 0.1.1, released 18 October 2026.** It is version 0.1.0's releases and code, unchanged, with the aDNA layer
that `MANIFEST.md` describes, and a README with a source named for each quotation and outside description, wordings
brought to their sources and three corrections, as `MANIFEST.md` lists.

**What it shows.** `README.md`, from its opening to *What failed*: residue mappings from human RyR1 to rabbit, mouse
and pig RyR1; the residue numbering of 26 structures, checked; the gate's state in the same 26; and the evidence for 299
residues fixed in advance, side by side, with no verdict. Three parts can be re-run from this repository: check A6 of
the mappings, the gate's radii and the composition, as *Re-running the results* gives them.

**What it does not show.** Nothing here reads a variant's effect, and nothing has been tested on known variants. The
README's *What ChannelScope does not claim* is the full list.

**What is open.** Each premise in the README's *Roadmap*, with what would count against it. Their summary for an agent
is `.agentic/what/context/context_channelscope_premises.md`; the work this version leaves undone is the README's *Next
steps*, to which `.agentic/how/backlog/AGENTS.md` points.

**Where to start.** `CLAUDE.md` for an AI agent, then `.agentic/AGENTS.md`.
