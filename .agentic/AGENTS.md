# .agentic/: ChannelScope's aDNA layer

This folder holds the project's aDNA triad, in aDNA's embedded form: the code and the releases stay where they are, and
the knowledge, operations and people that an agent needs sit here.

| Folder | What it holds |
|---|---|
| `what/` | What the project knows: context on its releases and on its premises |
| `how/` | How it works: the backlog, the templates, and where missions and sessions go |
| `who/` | Who is involved: how to contribute, and how the project is governed |

**Read first:** `README.md`, `MANIFEST.md` and `STATE.md` at the root, then the `AGENTS.md` in each folder here. The
rules every change keeps are in the root `CLAUDE.md`, under *Rules to keep*.

Nothing here is a working record of the project's own development: those stay in its private vault. What is here is
written for someone starting from this repository.
