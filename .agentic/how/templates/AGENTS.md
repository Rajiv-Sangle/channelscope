# how/templates/: shapes for new files

| Template | For |
|---|---|
| `template_session.md` | One agent working session, in your own copy (`how/sessions/`) |
| `template_mission.md` | The test of one premise, opened only with its criteria fixed in advance (`how/missions/`) |

Copy a template, rename it, and fill each field. Every file in `.agentic/` starts with aDNA's base frontmatter:
`type`, `status`, `created`, `updated`, `last_edited_by` and `tags`; the `AGENTS.md` indexes omit `status`, as aDNA's
standard allows for a directory index.
