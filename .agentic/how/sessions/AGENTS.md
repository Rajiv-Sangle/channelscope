# how/sessions/: an agent's working sessions

This folder holds no session in the published repository. The project's own sessions are kept in its private development vault.

**In your own copy,** an agent working on ChannelScope keeps one file per session here, from
`how/templates/template_session.md`: what it set out to do, what it did, what it checked, and what it hands on. aDNA's
standard (version 2.5, section 8) describes the session lifecycle.

**Sessions are not merged.** A pull request carries the change and its evidence, not the session that produced it
(`who/coordination/AGENTS.md`).
