# how/missions/: tests of the premises

No mission is open. A mission here is the test of one premise from the README's *Where ChannelScope is going: the aim, and its premises*, and it opens only when its
test is written down before it runs: what it measures, on which inputs, and what result would count against the
premise, with any margin fixed in advance. `how/templates/template_mission.md` gives the shape.

A premise whose test is not yet written belongs in the backlog or an issue, not here, so that nothing in this folder
reads as a test that has not been designed.
